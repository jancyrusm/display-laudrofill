# LaundroFill: A Liquid Detergent Dispensing Machine

LaundroFill is an IoT liquid dispensing machine that features an LCD touchscreen and sensors that gather data on the laundry and environmental conditions. This information is sent to a central control unit comprised of an Arduino Mega and a Raspberry Pi. The Arduino handles real-time control of hardware components, while the Raspberry Pi manages complex data processing and the user interface.
